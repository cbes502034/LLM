# LLM 課程心智圖 · LLM Course Mind Map

整個網頁就是一個檔案：[index.html](index.html)。下載後用瀏覽器直接打開即可，不需要安裝任何東西（字型與 D3、KaTeX 從 CDN 載入，需要連網）。

每個步驟格子上的「★N」是這一步有幾個實務重點；想看完整分支，用展開區每一欄下方的「在心智圖展開全部」。

## 每個節點裡有什麼

- **一個節點只放一個技術名詞**，說明文字裡提到的關鍵字都拆成子節點，可以點進去。
- **同一概念也出現在**：同一個概念若出現在好幾個地方（例如 RAG 同時出現在知識檢索、提示策略、AI 安全），打開任何一處都會列出其他所有位置與完整路徑，並說明它在那裡怎麼用。共 170 條這類關聯；名稱相同但意思不同的（例如 LayerNorm 的 β 和 DPO 的 β）刻意不連。
- **關聯線**：593 條，每一條都標出關係類型（例如「解決問題」「替代方案」「構成元件」），並用一句話說明為什麼相關。
- **詳細說明**：分頁呈現直覺、數學、程式碼、歷史、比較、步驟、常見誤解等面向（共 321 個分頁）。
- **生活比喻**：每個領域、主題、概念至少 3 個，各有標題，挑一個看得懂的就好（共 1,208 個）。
- **實務重要度**：★★★ 核心 122 個、★★ 重要 172 個；流程圖展開時列出的就是這些。
- **應用場景** 173 則、**相關新聞** 48 則、**參考資料** 1,191 筆（多數連到 Wikipedia 或原始論文）。
- **講義勘誤** 34 則：講義原文有誤的地方會標出並說明正確內容。
- **出處標籤**：每個節點標示來自哪幾份講義，點標籤可以看該講義涵蓋了哪些節點。標成「補充」的節點是講義之外補上的背景知識。

## 操作方式

| 動作 | 方法 |
|---|---|
| 看一個步驟 | 點流程圖的步驟：它展開列出 ★ 重點，心智圖上反白它涉及的節點；再點一次或按 × 收起 |
| 看一個節點 | 點節點；它的上層路徑、底下展開的內容與關聯節點會反白，其餘淡化 |
| 展開／收合 | 點節點旁的數字圓鈕，或用「分支」選單一次展開全部 |
| 返回／前進 | 選取中再點別的節點或步驟時，前一個會被記下來。說明面板最上方的「← 返回」（Backspace）回到剛才看的內容；返回之後可以按「前進 →」（Shift + Backspace）再回去。返回後點了新的節點，前進紀錄就作廢，和瀏覽器一樣 |
| 取消選取 | 點地圖空白處或按 Esc（返回與前進的紀錄也會一起清空） |
| 上一步／下一步 | 選了流程圖的步驟時，用 ← → 方向鍵或說明面板底部的按鈕切換 |
| 搜尋 | 右上角搜尋框，中英文關鍵字都可以 |
| 分享 | 網址後面加 `#節點id`（例如 `index.html#rag`），或 `#流程/第幾步`（例如 `index.html#root/5` 是生命週期第 5 步） |

右上角三個下拉選單：**顯示**（只看重點、關聯線）、**分支**（全部展開、收合到主題）、**語言**（English／中文）。

「已掌握」進度與語言設定只存在自己瀏覽器的 localStorage，不會上傳。
