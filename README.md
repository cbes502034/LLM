# 機器學習到大型語言模型

一份學習講義，[機器學習到大型語言模型.pdf](機器學習到大型語言模型.pdf)，黑底、單一份 PDF、共四章：

1. 機器學習 Machine Learning
2. 深度學習 Deep Learning
3. 自然語言處理 NLP
4. 大型語言模型 LLM

開頭有一張圖把四個領域的關係串起來，說明為什麼照這個順序學。每一章內部都先建立跟任何案例無關的最基礎原理，一步一步疊加元件，疊完才代入例子；表格、流程圖、架構圖依內容性質選用。

## 第一章演算法速查表

正文每個演算法都是「底層概念→流程圖→逐步講解→具體例子→業界應用實例」的完整走法，這裡只列速查用的總表：名稱、應用場景、時間複雜度、優缺點。時間複雜度是理論上的量級估計，實際效能還要看資料本身的分布與實作方式，僅供判斷「資料量大時哪個方法會先變慢」的直覺參考（n＝訓練樣本數、d＝特徵數、t＝樹或弱分類器的數量、s＝支持向量的數量、c＝類別數）。

| 名稱 | 應用場景 | 訓練時間複雜度 | 預測時間複雜度 | 優缺點 |
|---|---|---|---|---|
| **線性迴歸**<br>Linear Regression | 預測連續數值：房價、銷量、氣溫、需求預測 | O(n·d²)（正規方程）或每輪 O(n·d)（梯度下降） | O(d) | 優：簡單快速、係數可直接解釋每個因素的影響力。<br>缺：只能抓線性關係，資料若是曲線關係會擬合不良。 |
| **Logistic Regression**<br>邏輯迴歸 | 信用風險評分、廣告點擊率預估、二元分類且需要機率輸出的場景 | 每輪 O(n·d)，需迭代到收斂 | O(d) | 優：輸出是機率不只是類別、可解釋性高、訓練快。<br>缺：只能抓接近線性的決策邊界，遇到複雜非線性關係表現有限。 |
| **決策樹**<br>Decision Tree | 需要把判斷邏輯攤開給非技術人員看的場景，如醫療輔助診斷、審核規則 | 約 O(n·d·log n) | O(log n)（樹深度） | 優：規則直覺好理解、不需要特徵標準化。<br>缺：單棵樹容易過擬合，資料稍變樹的形狀可能大幅改變（不穩定）。 |
| **Random Forest**<br>隨機森林 | 特徵多、需要穩定準確度優先於極致可解釋性的場景，如醫療影像、生物資訊特徵重要性分析 | O(t·n·d·log n) | O(t·log n) | 優：比單一決策樹穩定、抗雜訊、可評估特徵重要性。<br>缺：模型較大、佔記憶體，不如單棵樹好逐步解釋給別人聽。 |
| **AdaBoost**<br>自適應提升 | 資料相對乾淨、想從一堆弱模型榨出更高準確度的場景，Kaggle 競賽常見 | O(t·n·d) | O(t) | 優：準確度通常優於單一模型，理論保證穩固。<br>缺：對雜訊資料敏感（會過度關注錯誤樣本）、訓練是序列化的，較難平行化。 |
| **KNN**<br>K-最近鄰居 | 資料量不大、決策邊界不規則、推薦系統的相似項目查找 | O(1)（只是儲存資料，沒有真正訓練） | O(n·d)（暴力法，需跟全部資料比對距離） | 優：邏輯直覺、不需要訓練、天生適合處理不規則邊界。<br>缺：資料量大時每次預測都很慢，且對特徵尺度／單位敏感，須先標準化。 |
| **SVM**<br>支持向量機 | 特徵維度高但樣本數不算巨大的場景，如文字分類、生物資訊基因分類、早期人臉辨識 | O(n²)～O(n³)（視實作與 Kernel 而定） | O(s·d) | 優：高維度資料表現好、理論基礎扎實、Kernel trick 可處理非線性。<br>缺：樣本數一大訓練就明顯變慢，Kernel 與其參數需要實驗調整。 |
| **貝氏分類器**<br>Naive Bayes | 文字分類（垃圾郵件、新聞分類）、需要極快訓練與預測速度的場景 | O(n·d) | O(c·d) | 優：訓練與預測都極快、小資料量也能用、對文字分類效果穩定。<br>缺：「特徵互相獨立」的假設在真實資料中常不成立，機率估計可能失準。 |

## 第二章優化器速查表

優化器不是獨立的預測模型，是「知道梯度之後怎麼跨步」的訓練機制，四種方法每一步的計算量都是 O(d)（d＝參數量），差異主要在收斂速度與額外需要的記憶體，所以欄位換成核心邏輯與優缺點。

| 名稱 | 全名 | 核心邏輯 | 優缺點 |
|---|---|---|---|
| **SGD** | Stochastic Gradient Descent，隨機梯度下降 | weight = weight − lr × gradient，只看當下的梯度 | 優：邏輯最簡單、不需要額外記憶體。<br>缺：收斂慢，容易在最小值附近震盪。 |
| **Momentum** | 動量法 | 模擬物理慣性，同方向持續調整就加速，方向反覆就減速 | 優：比 SGD 快、能抑制部分震盪。<br>缺：多一份速度向量的記憶體，遇到強烈轉向仍可能過衝。 |
| **AdaGrad** | Adaptive Gradient，自適應梯度 | 依每個參數的歷史梯度大小自動調整各自的學習率 | 優：常變動的參數自動放慢、穩定的參數維持步伐。<br>缺：訓練後期學習率會越縮越小，容易提早停滯。 |
| **Adam** | Adaptive Moment Estimation，自適應動量估計 | 結合 Momentum 與 AdaGrad 的優點，並做偏差校正 | 優：收斂通常最快最平滑，是目前的預設選擇。<br>缺：需要額外維護兩組動量估計，記憶體開銷約為 SGD 的兩倍。 |

## 第三章分詞方法速查表

| 名稱 | 核心原理 | 優缺點 | 用在哪 |
|---|---|---|---|
| **BPE**<br>Byte Pair Encoding，位元組對編碼 | 反覆合併語料裡最常出現的相鄰字元對，直到詞彙表達到預設大小 | 優：常見詞合併成完整 token 效率高，罕見詞退回子詞／字母不會變成無法辨識的未知詞。<br>缺：合併順序依語料統計決定，不同語料訓練出的詞彙表不通用。 | GPT 系列（含 OpenAI 的 tiktoken）、BERT |
| **SentencePiece** | 把空格也當成普通字元，直接在字元層級分詞，不依賴人工先斷詞規則 | 優：不需要語言專屬的斷詞規則，天生適合中日文這類字間無空格的語言。<br>缺：對已經有良好斷詞工具的語言，效益不如語言專屬方法明顯。 | T5、多語言模型 |

## 第四章生成策略速查表

生成策略是「決定下一個字時，從機率分布裡怎麼選」的取捨，不是模型本身，所以欄位換成邏輯與適合情境。

| 名稱 | 邏輯 | 適合情境 |
|---|---|---|
| **Greedy Search**<br>貪婪搜尋 | 每一步都選機率最高的字 | 需要穩定、可重現的輸出，且不在意偶爾單調重複 |
| **Beam Search**<br>集束搜尋 | 同時保留多條候選句子繼續生成，最後選整體機率最高的一條 | 翻譯、摘要這類講求整體句子品質、可以接受較高運算成本的任務 |
| **Top-K 採樣** | 只在機率最高的 K 個候選裡依機率隨機抽一個 | 想要一點變化但仍希望候選範圍可控、K 值好調整的場景 |
| **Top-P 採樣**<br>Nucleus Sampling，核採樣 | 依機率由高到低累加候選字，加到累積機率超過 P 就停 | 對話助理的預設選擇，候選範圍會隨模型的確定程度動態縮放 |
| **Temperature**<br>溫度 | 生成前先重新調整整個機率分布的平滑程度 | 數值調低接近 Greedy（適合程式碼生成），調高增加多樣性（適合創意寫作） |
