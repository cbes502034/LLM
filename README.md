## 每個節點裡有什麼

- **一個節點只放一個技術名詞**，說明文字裡提到的關鍵字都拆成子節點，可以點進去。
- **詳細說明**：分頁呈現直覺、數學、程式碼、歷史、比較、步驟、常見誤解等面向（共 321 個分頁）。
- **生活比喻**：每個領域、主題、概念至少 3 個，各有標題，挑一個看得懂的就好（共 1,208 個）。
- **關聯線**：566 條，每一條都標出關係類型（例如「解決問題」「替代方案」「構成元件」），並用一句話說明為什麼相關。
- **實務重要度**：★★★ 核心 122 個、★★ 重要 172 個；「只看重點」模式會淡化其他節點。
- **應用場景** 173 則、**相關新聞** 48 則、**參考資料** 1,191 筆（多數連到 Wikipedia 或原始論文）。
- **講義勘誤** 34 則：講義原文有誤的地方會標出並說明正確內容。
- **出處標籤**：每個節點標示來自哪幾份講義，點標籤可以看該講義涵蓋了哪些節點。標成「補充」的節點是講義之外補上的背景知識。

## 操作方式

| 動作 | 方法 |
|---|---|
| 看一個節點 | 點節點；它的上層路徑、子節點與關聯節點會反白，其餘淡化 |
| 展開／收合 | 點節點旁的數字圓鈕，或用「分支」選單一次展開全部 |
| 取消選取 | 點地圖空白處或按 Esc |
| 上一個／下一個節點 | ← → 方向鍵 |
| 搜尋 | 右上角搜尋框，中英文關鍵字都可以 |
| 分享某個節點 | 網址後面加 `#節點id`，例如 `index.html#rag` |

右上角四個下拉選單：**檢視**（心智圖／流程圖）、**顯示**（只看重點、關聯線）、**分支**（全部展開、收合到主題）、**語言**（English／中文）。

「已掌握」進度、語言與檢視設定都只存在自己瀏覽器的 localStorage，不會上傳。
